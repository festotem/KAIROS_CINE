# Guia do Usuário - Aplicativo de Gestão Audiovisual

Este documento fornece instruções sobre como utilizar o aplicativo web de gestão para produtoras audiovisuais.

## Visão Geral

O aplicativo permite gerenciar:
- Cadastro de clientes e projetos
- Cadastro de colaboradores
- Orçamentos de projetos
- Cronogramas de produção

## Acesso ao Sistema

Acesse o aplicativo através da URL fornecida após a implantação. O sistema foi projetado para funcionar em dispositivos desktop e móveis.

## Funcionalidades Principais

### Dashboard

A página inicial apresenta cards para acesso rápido às principais seções do sistema:
- Clientes
- Colaboradores
- Orçamentos
- Cronogramas

### Gestão de Clientes

Na seção de Clientes, você pode:
1. Visualizar a lista de clientes/projetos cadastrados
2. Adicionar novos clientes/projetos através do botão "Adicionar Cliente"
3. Visualizar detalhes de um cliente/projeto clicando em seu nome
4. Editar ou excluir informações de clientes/projetos

Ao cadastrar um cliente/projeto, preencha informações como:
- Título do projeto
- Produtora
- Contato (nome, telefone, email)
- Especificações técnicas (formato, câmera, resolução, codec)
- Duração e número de episódios

### Gestão de Colaboradores

Na seção de Colaboradores, você pode:
1. Visualizar a lista de colaboradores cadastrados
2. Adicionar novos colaboradores através do botão "Adicionar Colaborador"
3. Visualizar detalhes de um colaborador clicando em seu nome
4. Editar ou excluir informações de colaboradores

Ao cadastrar um colaborador, preencha informações como:
- Dados pessoais (nome, função, contato)
- Dados empresariais (quando aplicável)
- Representante legal
- Detalhes da prestação de serviços
- Dados bancários

### Gestão de Orçamentos

Na seção de Orçamentos, você pode:
1. Visualizar a lista de orçamentos cadastrados
2. Criar novos orçamentos através do botão "Criar Orçamento"
3. Visualizar detalhes de um orçamento clicando em seu nome
4. Editar ou excluir orçamentos

Ao criar um orçamento, você pode:
- Selecionar o cliente/projeto
- Adicionar itens de orçamento organizados por categorias
- Especificar quantidades, valores unitários e multiplicadores
- Acompanhar o valor total calculado automaticamente

### Gestão de Cronogramas

Na seção de Cronogramas, você pode:
1. Visualizar a lista de cronogramas cadastrados
2. Criar novos cronogramas através do botão "Criar Cronograma"
3. Visualizar detalhes de um cronograma clicando em seu nome
4. Editar ou excluir cronogramas

Ao criar um cronograma, você pode:
- Selecionar o cliente/projeto
- Definir o período do cronograma
- Adicionar tarefas com datas de início e término
- Atribuir responsáveis às tarefas
- Atualizar o status e porcentagem de conclusão das tarefas

## Dicas de Uso

- Mantenha os dados de clientes e colaboradores sempre atualizados
- Utilize as categorias de orçamento para organizar melhor os itens
- Atualize regularmente o status das tarefas no cronograma
- Utilize a barra de navegação superior para alternar entre as seções

## Suporte

Em caso de dúvidas ou problemas, consulte a documentação técnica ou entre em contato com o administrador do sistema.
